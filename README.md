# Heltec V3 Mesh Pinger
This is an example project demonstrating how to use the [MTSimpleBroadcast](https://github.com/jrddupont/MTSimpleBroadcast) library to broadcast messages over the Meshtastic network using a Heltec V3 LoRa board.

## Example Usage
### Environment
Running on a [Heltec V3](https://heltec.org/project/wifi-lora-32-v3/).  
Make sure you have an antenna connected *before* powering it on, as operating without an antenna can damage the radio.
  
Requires these libraries:
* jgromes/RadioLib
* rweather/Crypto
* densaugeo/base64
